# live-market-site-jhon

Production repository for LIVETVMARKET storefront.

### Setup Instructions
1. Copy `config/db.example.php` to `config/db.php` and configure your database credentials.
2. Copy `config/payment_bridge.example.php` to `config/payment_bridge.php` and set your secret key.
3. Configure your web server document root to point to this directory.
